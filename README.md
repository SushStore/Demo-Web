# ☕ L'Aura — Café & Panadería Artesanal

**L'Aura** es una landing page de alta fidelidad diseñada para una cafetería de especialidad y panadería artesanal. El proyecto destaca por su estética minimalista, tipografía refinada y una experiencia de usuario fluida, ideal para marcas que buscan proyectar calidad y calidez.

## ✨ Características del Proyecto

* **🎨 Diseño Premium:** Paleta de colores cálida (terracota, crema, oliva) inspirada en elementos naturales y artesanales.
* **📜 Animaciones de Revelado:** Sistema de "scroll-reveal" mediante *Intersection Observer API* que dota de dinamismo a la navegación.
* **🥐 Menú Interactivo:** Sistema de pestañas (Tabs) para alternar entre las categorías de Café y Repostería de forma instantánea.
* **📱 Totalmente Responsivo:** Diseño adaptado meticulosamente para dispositivos móviles, tablets y escritorio.
* **🖼️ Galería Visual:** Layout de rejilla (Grid) moderno para mostrar productos y momentos de la marca.
* **🟢 Integración con WhatsApp:** Botón flotante (FAB) animado para facilitar pedidos directos y reservas.

## 🛠️ Stack Técnico

* **HTML5 Semántico:** Para un SEO optimizado y estructura clara.
* **CSS3 & Tailwind CSS:** Estilos personalizados combinados con la agilidad de Tailwind para el espaciado y layout responsivo.
* **JavaScript (Vanilla):** * Gestión del estado del Navbar al hacer scroll.
    * Lógica de filtrado de pestañas del menú.
    * Implementación del observador de intersección para animaciones.
* **Google Fonts:** Integración de *Playfair Display* (Serif) y *Montserrat* (Sans-serif).
